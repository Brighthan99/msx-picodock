# Changelog

Semantic versioning. The number lives in [`VERSION`](VERSION) and moves with
every change that ships — the server prints it on start-up and the TUI carries
it in the title bar, which is the point: a bug report that says "v0.70.0" is
answerable, one that says "the build I made some time in July" is not.
